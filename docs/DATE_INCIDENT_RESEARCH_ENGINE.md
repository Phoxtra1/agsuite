# Date & Incidents — Shared Dipa Research Route

## Runtime architecture

The Date & Incidents page calls the same `docs-intelligence` function route used by other Dipa-backed features. It sends the dedicated `historical_events_search` action with an exact ISO date (including the year), region and category. The existing Appwrite adapter routes that invocation to agSuite function `69689f59003426b9e5e3`.

The agSuite handler uses Gemini 2.5 Flash with Google Search grounding for this action. The API key is server-side only; it is never exposed through a browser `VITE_` variable. The page renders separate historical incident cards; it does not embed the general Info Discovery publication/repository search results.

## Required Appwrite function variable

Set `GEMINI_API_KEY` in Appwrite Console → Functions → agSuite → Settings → Variables. Do not commit the key or expose it to browser code.

## Function settings and deployment

- Function ID: `69689f59003426b9e5e3`
- Runtime: Node.js 18 or later.
- Timeout: 60 seconds.
- Source: `appwrite/functions/agsuite/src/main.js`.
- Deploy with the repository's Appwrite CLI configuration after setting the server-side key.

The code is committed to GitHub; it is not deployed to the live Appwrite function by a GitHub source commit alone. The root `appwrite.json` now registers function `69689f59003426b9e5e3` and points its deployment path to `appwrite/functions/agsuite` with `src/main.js` as the entrypoint.

## Result requirements

- Exact occurrence date must equal the selected full date, including year.
- Do not substitute a report/publication date, anniversary, or same month/day in another year.
- Africa is prioritised by default; international events remain included.
- Return only prominent, well-documented events; do not pad the list.
- Display links from Google Search grounding metadata, not arbitrary URLs generated by the model.
- Distinguish corroborated, single-source and contested records, and include caveats/date evidence.

3. Authenticate the Appwrite CLI against the `amineva` project and run `appwrite push functions` from the repository root.
